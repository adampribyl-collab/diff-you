# DIFF.YOU

Náhled webu studia DIFF.YOU – manikúra a modeláž nehtů.

**Web:** https://adampribyl-collab.github.io/diff-you/

Stránka je jeden samostatný soubor `index.html` (fotky, fonty i skripty jsou uvnitř). Zdroje a postup úprav jsou v soukromém repozitáři `diff-you-web`; po úpravě tam stačí zkopírovat soubor z `web/` sem jako `index.html` a nahrát.
